# 界面设计

[返回首页](../README.md) · [开发说明](development.md) · [配色](color-research.md)

当前界面采用 Figma A v2，围绕层结构编辑、光学响应和厚度扫描三个工作区组织。
界面使用中性黑白灰，以表格和图表为主，颜色留给数据曲线、热图和必要的状态提示。
图例文字使用中性色，短线对应曲线颜色；坐标、网格和场强分层边界也使用中性灰。

## 布局

结构页左侧放参数和层表，右侧放结构剖面，两栏底边对齐。
响应页先显示目标指标，再展示光谱或场强，导出按钮放在图表旁。
扫描页以「单层扫描」「双层扫描」区分模式，左侧放条件和最大响应度，右侧图表占满剩余宽度，两栏等高。

| 项目 | 桌面尺寸 |
| --- | --- |
| 顶栏 | 高 64px |
| 页面左右边距 / 分栏间距 | 32px / 24px |
| 结构剖面 / 扫描条件栏 | 宽 312px / 296px |
| 按钮 / 输入框 | 高 40px / 44px |
| 表格行 / 表头 | 高 42px / 48px |
| 正文 / 默认圆角 | 14px / 8px |

宽度小于 1200px 时，导航换行，结构剖面移到表格下方。
700px 及以下采用单栏内容、两列参数；表格前三列依次为层序、名称、厚度，其余列在表格内横向滚动。
指标和工具条按可用宽度换行，避免撑宽整页。

## 组件

层表使用 AG Grid Community 的 Quartz 主题，沿用它的编辑器、表头菜单、列宽调整和键盘导航。
响应层选项和行操作居中，图标使用 Lucide。
筛选放在表头菜单中，不单独占一行；层序有物理含义，因此关闭排序。

按钮、字段和标签通过公共样式保持一致，模型设置使用原生 `dialog`。
弹窗支持关闭并将焦点返回入口，表格编辑支持确认、取消和无效值提示。

## 结构剖面

层条等高，保留每层名称与实际厚度。
灰阶按当前结构的最薄层到最厚层映射，越厚越深，同一厚度使用同一颜色。
所有层厚度相同时使用中间灰度，深色层条使用白字。

顶部显示结构总厚度，底部标注入射方向。
剖面和 SVG 导出使用相同的层序与灰阶规则，具体配置见 [配色说明](color-research.md)。

## 数据与状态

页面初始不显示计算结果，运行仿真后填入指标、曲线、坐标轴和能量摘要。
结构或模型变化后清空旧结果，重新计算前禁用相应的结果导出。
扫描结果来自当前参数和采样点，设计稿中的数值不作为页面的固定内容。

标签保留字段名和单位，提示只在需要操作或修正输入时出现。
设计稿编号、布局说明和重复状态文字留在文档中。
