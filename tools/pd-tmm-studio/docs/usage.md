# 使用说明

[返回首页](../README.md) · [开发说明](development.md)

## 编辑结构

层表从上到下按顶部金属到衬底排列，光从衬底侧入射。
先设置目标波长、光谱范围和采样点数，再调整各层参数并选择响应层。

| 操作 | 方法 |
| --- | --- |
| 修改名称、厚度、n/k | 点击单元格编辑，`Enter` 确认，`Esc` 取消 |
| 更换材料 | 在材料列选择，n/k 会恢复为该材料的预设值 |
| 选择响应层 | 点击对应行的单选按钮 |
| 增删或移动层 | 使用「添加层」及行末的上移、下移、删除按钮 |
| 调整列宽、筛选 | 拖动列边界，或打开表头菜单 |

层序参与计算，表格不提供按数值排序。
右侧剖面与层表顺序一致，层越厚，灰色越深；数值标签显示实际厚度。

「模型设置」中可以调整边界介质、色散、高斯角谱和载流子收集效率。
「恢复默认」会恢复配置中的结构、模型和扫描参数，并清空已有结果。

## 运行仿真

点击「运行仿真」后，页面切换到光学响应，显示目标波长的响应度、吸收率和光谱峰值。
可在光谱与腔内场强之间切换；场强以入射侧为深度起点，并归一化到最大值为 1。

修改结构或模型后，旧结果会清空，相关导出按钮暂时禁用，重新运行即可更新。
输入有误时，按页面提示修正范围或数值。

## 厚度扫描

「单层扫描」选择一层，设置厚度起点、终点和采样数，得到厚度与响应度的关系曲线。
「双层扫描」选择两个不同的层，分别设置 X、Y 范围及每个方向的采样数，得到响应热图。

扫描使用当前目标波长和模型设置。
最优值取自本次离散采样点，扫描结果不会自动写回层表；需要采用该厚度时，在层表中手动修改后重新仿真。

## 导入与导出

| 文件 | 内容 | 入口 |
| --- | --- | --- |
| JSON | 层的名称、材料、厚度和排列顺序 | 顶栏「导入」「导出」 |
| CSV | 本次计算的光谱数据 | 光学响应「导出 CSV」 |
| SVG | 结构剖面、双轴光谱、响应度、单层扫描或双层热图 | 对应图表旁的导出按钮 |

结构 JSON 示例，厚度单位为 nm：

```json
{
  "version": 1,
  "stackOrder": "top-to-bottom",
  "layers": [
    { "name": "Au mirror", "material": "Au", "thickness": 100 },
    { "name": "InGaAs absorber", "material": "InGaAs", "thickness": 750 }
  ]
}
```

导入也接受直接提供的层数组，默认按从顶部到衬底的顺序读取。
若使用 `"stackOrder": "incident-to-exit"`，则按从入射侧到出射侧的顺序读取。
材料名称必须在页面材料库中，厚度必须为正数。

JSON 不保存手动修改的 n/k、响应层选择或模型设置。
导入时从材料库恢复 n/k，先按层名中的吸收层标记识别响应层，再尝试 InGaAs；导入后请检查响应层和模型设置。
页面不会自动保存编辑内容，刷新前可先导出需要保留的结构。

## 模型范围

响应度由目标层吸收和载流子收集效率换算，场强采用法向入射 TE 解。
开启色散后，InP 使用 Sellmeier 模型，InGaAs 默认使用 O-band 校准表，也可切换到保守的 Adachi 模型。
双参数扫描最多使用 10 个角采样。

本工具计算光学响应，未包含 RC、渡越时间或电学带宽模型。
